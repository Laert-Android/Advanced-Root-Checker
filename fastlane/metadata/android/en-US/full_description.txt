Advanced Root Checker detects root indicators on your
Android device. All 17 checks run entirely offline.
No internet connection required, no data sent anywhere.

WHAT IT DETECTS:
- su binaries in common and hidden paths
- Magisk and Magisk modules
- SuperSU and SuperUser APKs
- BusyBox binary
- Xposed Framework
- Known root manager apps
- Potentially dangerous apps
- Root cloaking apps (Shamiko, MagiskHide)
- Dangerous system properties
- Read-write /system mount
- Writable /system partition
- SELinux permissive mode
- Test-keys build signature
- Suspicious build fingerprint
- Root native test

DEVICE SECURITY INFO:
- Android version and API level
- Security patch level
- Build type and fingerprint
- Bootloader status
- Screen lock status
- SELinux status
- CPU architecture
- Kernel version

IMPORTANCE OF ROOT:
- What is root explained
- Benefits of rooting
- Risks and warnings
- Safety tips for rooted devices

PRIVACY:
- No internet permission
- No ads or ad SDKs
- No analytics or tracking
- No data collection of any kind

OPEN SOURCE:
Full source code on GitHub under GPL-3.0.

Compatible with Android 5.0 and above.
