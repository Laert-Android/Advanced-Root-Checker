Advanced Root Checker detects root indicators on your
Android device. All 35 checks run entirely offline.
No internet connection required, no data sent anywhere.

WHAT IT DETECTS:
- su binaries in common and hidden paths
- Magisk, Magisk Modules and Magisk DenyList
- Zygisk framework and Zygisk modules
- KernelSU root solution
- APatch root solution
- SuperSU and SuperUser APKs
- BusyBox binary
- Xposed Framework
- Known root manager apps
- Potentially dangerous apps (Lucky Patcher etc)
- Root cloaking apps (Shamiko, MagiskHide)
- In-app-billing hijack (Lucky Patcher purchase interception)
- Dangerous system properties
- Read-write /system mount
- Writable /system partition
- SELinux permissive mode
- Test-keys build signature
- Suspicious build fingerprint
- Root native test
- Play Integrity heuristics (offline approximation only, not a real Google API verdict)
- Emulator detection
- ADB status
- Developer options check
- OTA updates status
- Verified Boot status
- Knox status (Samsung)
- Anti-rollback protection
- Treble support
- Native capability check
